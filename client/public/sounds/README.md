# Background Music

Place your background music file here:

**File name:** `bg_sound.mp3`

The audio file will be played in a loop on the website. Users can control playback using the floating music button in the bottom-right corner of the page.

## Supported Format
- MP3 (audio/mpeg)

## Notes
- The audio starts paused by default (user must click the button to play)
- The audio loops continuously when playing
- File should be optimized for web (reasonable file size for faster loading)
